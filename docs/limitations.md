# Limitations

This list is kept honest and current.

- **Correlation and reconciliation, not proof of intent.** Tiresias shows *that* figures reconcile to an event. It cannot show *why* management made a decision unless the evidence exists in structured data.
- **Structured data only (v1).** Narrative text (press releases, MD&A) is not parsed. When the next "why" needs text, the run ends at `evidence-frontier` with a pointer to where to look.
- **Bounded catalog.** The agent discovers sources only from `catalog/sources.yaml`, by design (scope and reproducibility).
- **No segment data** in XBRL `companyfacts`.
- **Residuals are reported, not explained away.** For example, GE HealthCare's revenue is $114M short of GE's restatement delta.
- **Judges can't run Zetaris or Nightshift.** Sample mode uses cached query results and rule-based agents; the live path is shown in the demo video and traces.
- **Models advise; they don't decide.** In a live run at depth `thorough` or `deep` (ADR-0011; the default `quick` calls no model) the Nightshift lanes may add candidates, a second opinion and the action's wording (ADR-0010), but every accepted link still rests on SQL rows and the rule critic's tests, and a disagreement keeps the rule verdict unless a human prunes at the gate. The hypothesiser lane only fills branch slots the rules leave free, so on the three examples it rarely runs. Nightshift picks the model itself (the trace logs `routed_model`), and each call takes tens of seconds (24–50 s measured on 2026-10-24), so a live run with the lanes on takes minutes (measured on case 01: about 1.5 min more at `thorough`, about 2.5 min more at `deep`); the expected wait is returned before the run starts, and `quick` keeps the rule-only timing.
- **The model-call evidence is one committed live run.** Nightshift and Nemotron are shown by one fresh-state live trace in which two of the three lanes ran and one of four replies was rejected; the full list of what that trace does and does not show is in [sponsor-technology.md](sponsor-technology.md#what-the-model-call-trace-shows-and-what-it-does-not).
- **Sample-mode "registration" does not call Zetaris.** When Loop B registers a discovered company in sample mode, it checks that the company is in `data/sample/` and serves it from there; the trace says `registration: "sample"`. Only live mode registers sources in Zetaris.
- **The hosted demo (https://tiresias.palmlore.com) is demo grade.** It runs on deliberately small resources so its cost stays bounded: one instance (1 vCPU and 1 GiB for the agent, 1 vCPU and 512 MiB for the memory service), at most 4 runs at a time (a fifth gets 429 `TooManyRuns`: retry shortly), no autoscaling, no CDN, no login. Under load it is slow or busy rather than more expensive. It is sample mode only (cached SEC data, rules only: no live Zetaris, no Nightshift models), its H-MEM memory is shared by every visitor and lost when the instance restarts, and memory purge is off. Live mode and full performance run locally.
- **Runs are remembered in memory only.** `GET /runs/{id}` forgets a run after the agent restarts or once 50 newer runs finished; the trace file in `logs/` stays.
- **Not investment advice.** Outputs support an analyst's own review.
